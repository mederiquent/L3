# CM 3 — Quiz

## Q1

Énoncé d'un QCM à une seule bonne réponse.

- [ ] Choix A
- [x] Choix B : la bonne réponse
- [ ] Choix C
- [ ] Choix D

### Correction

**Réponse : B.** Pourquoi B est juste, en s'appuyant sur le cours.

- **A** est faux : …
- **C** est faux : c'est le piège classique de la fiche vigilance (renvoi **Vn** s'il s'agit d'un point « À vérifier »).
- **D** est faux : …

## Q2 · Thème de la question

Énoncé d'un QCM à plusieurs bonnes réponses (plusieurs cases cochées). Le sous-titre après « · » est facultatif ; le site indique lui-même « Une seule réponse », « Plusieurs réponses possibles » ou « Question ouverte ».

- [x] …
- [ ] …
- [x] …

### Correction

**Réponses : A et C.** Justification de chaque choix, juste ou faux.

## Q3 · Calcul

Énoncé d'un exercice ou d'une question ouverte : sans cases, l'étudiant cherche puis affiche la correction.

### Correction

Résolution détaillée, étape par étape, conditions vérifiées (CPO, CSO, signes, domaine…), résultat encadré ou mis en gras.
